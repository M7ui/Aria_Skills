# 作曲规则总纲（写音符前必读）

> 来源：AI-Music-Roll 网页应用内嵌系统提示词（app.js SYSTEM_PROMPT_BASE）提取精修。
> 目标：让 AI 作曲结果听起来像「人写的」，而不是「机器生成的」。
> 逐步实操与真实歌曲案例见 `melody-chord-writing.md`。

## 0. 卷帘规格（硬约束）

| 项目 | 值 |
|------|-----|
| MIDI 音高范围 | 36 (C2) – 96 (C7)，推荐旋律区 48–84 |
| 时间单位 | 拍（四分音符 = 1 拍） |
| 网格分辨率 | 默认 0.25 拍；追求更细律动时可用 0.125 拍或双轨错位（validate 非 strict 只警告） |
| 默认速度 | 120 BPM（40–300） |
| 默认拍号 | 4/4 |
| 力度 | 1–127 |

音高速查：C4=60（中央 C），每八度 ±12。C2=36、C3=48、D3=50、E3=52、F3=53、G3=55、A3=57、B3=59、C4=60、D4=62、E4=64、F4=65、G4=67、A4=69、B4=71、C5=72、D5=74、E5=76、F5=77、G5=79、A5=81、B5=83、C6=84、C7=96。

## 1. 段落结构规范（先定结构，再写音符）

动笔前先规划 3–5 个段落。各段特征：

| 段落 | 小节数 | 音域 | 力度 | 密度 | 要点 |
|------|--------|------|------|------|------|
| intro 前奏 | 2–4 | 50–60 | 50–65 | 稀疏 | 只用 2–3 个音高制造悬念，别提前泄露完整旋律 |
| verse 主歌 | 8 | 55–72 | 65–85 | 中等 | 「讲故事」段，4 小节乐句+休止，对话式节奏 |
| pre_chorus 预副歌 | 4 | 60–76 | 75→95 | 渐强 | 过渡段，音高上行、力度渐增 |
| chorus 副歌 | 8 | 65–84 | 85–110 | 饱满 | THE HOOK：更高、更响、节奏更强、最难忘的动机 |
| bridge 桥段 | 4–8 | 55–72 | 70–85 | 对比 | 与主/副歌不同的和声进行或律动 |
| breakdown 减配段 | 4–8 | 48–65 | 50–70 | 稀疏 | 抽离配器、压低能量，为高潮蓄力 |
| build_up 铺垫段 | 4–8 | 55–78 | 70→110 | 渐强 | 上行音型+力度渐强，时值越来越短 |
| drop 高潮 | 8–16 | 65–84 | 95–120 | 最大 | 能量峰值，密集编曲，高力度 |
| outro 尾声 | 4 | 48–60 | 50–65 | 渐弱 | 下行轮廓、力度递减，落在主音上解决 |

## 2. 和弦进行规范（第二步）

定好段落后定义和弦进行（写进 chords.json 供 analyze 检查强拍匹配）：

- C 大调经典示例：`C(60) → G(67) → Am(69) → F(65)`，每和弦 4 拍（1 小节）
- 和弦类型：`maj, min, dim, aug, maj7, min7, dom7, m7b5, dim7, sus4, sus2, maj9, min9, add9`
- 默认强拍（4/4 的第 1、3 拍）落在当前小节的和弦音上；允许有意的非和弦音强拍（挂留/倚音/蓝调音），强拍和弦音占比可降到 60–80%
- 详细配和弦步骤：优先“旋律音作三音/根音/五音”、和声节奏、真实编曲案例见 `melody-chord-writing.md` §2

## 3. 七大作曲规则

> 以下规则是默认值，不是绝对禁令。有意打破时读 `anti-formula.md`，并在交付摘要里记录目的。

### 规则 1 — 动机驱动
先发明一个 2–5 音的节奏动机，再发展 4 次以上：
```
动机:   C4 · E4 G4 ·     (第 1 拍休止，1.5 拍进，2.0 拍长音)
重复:   C4 · E4 G4 ·     (原样重复 → 建立熟悉感)
上移四度: F4 · A4 C5 ·   (同节奏移调 → 更兴奋)
变奏:   F4 E4 D4 ·· C4   (节奏变化，下行解决)
```
真正的旋律 = 动机 × 变奏，**不是**连续的上下行音阶。
8 种发展技法的完整配方（原样重复/模进/倒影/逆行/拉长缩短/碎片化/音程扩展/节奏变奏，含 MIDI 例子）见 pattern-library.md §4。
真实歌曲中的动机/环绕/倒影案例与 MIDI 写法见 `melody-chord-writing.md` §3.4。

#### 规则 1 补充 — 模块化乐句结构（连贯性的来源，2026-08 联网调研增强）

动机只是最小单元。连贯的旋律按「动机(2–5 音) → 乐节(2 小节) → 乐句(4 小节) → 乐段(8–16 小节)」四级组装，
**先把乐句计划写成表，再写音符**：

| 层级 | 长度 | 任务 | 检查信号（analyze） |
|------|------|------|---------------------|
| 动机 motif | 2–5 音 | 可识别的音程+节奏特征 | motif_reuse > 0 |
| 乐节 | ≈2 小节 | 动机的陈述/模进 | — |
| 乐句 phrase | ≈4 小节 | 有明确终止点，句尾休止 ≥0.5 拍或长音 ≥2 拍 | phrase_count、phrase_endings_pc |
| 乐段 section | 2–4 个乐句 | 同头异尾建立连贯，结尾收束 | contour_reuse_pairs、final_on_tonic |

四大乐句图式（详表见 pattern-library.md §4.2/§4.2.1）：

1. **起承转合四句体**（a–a'–b–a'）：起句陈述动机；承句同头变化重复、落属音（开放）；转句换音区/离调/加密节奏制造对比；合句再现起承材料、落主音收束。华语流行/民谣/古风默认图式
2. **Period 4+4**：前后句同一开头材料，前句半终止（停 V），后句完全终止（V–I）——平衡、歌谣感
3. **Sentence 2+2+4**：2 小节动机 + 2 小节模进 + 4 小节碎片化加速冲向终止——推进感、适合主题呈示
4. **流行重复图式**：AABA / AAAB / ABAB / AABC——副歌默认 AABA/AAAB，主歌可用 ABAB/AABC

连贯性三板斧（成本最低、效果最直接）：

- **同头异尾**：相邻乐句共享前 2–3 音的音程走向，只改结尾（period/起承转合/AABA 的共同本质）
- **问句开放、答句收束**：前句落属音/上主音，后句与末句落主音；全曲最后一音 = 主音长音（≥2 拍）
- **顶真（鱼咬尾）**：后句第一音 = 前句结束音，句间像链条扣住（《孟姜女》《茉莉花》同款手法）

analyze（1.2.0+）的 structure_score 逐项检查以上信号；写完后用 `--key-root` 跑一遍，
structure_score < 6 时先修乐句计划，不要急着改单个音符。

### 规则 2 — 和弦音停留
- 默认强拍音符是与当前和弦的和弦音（用 `aria-midi scale --chord` 查）
- 非和弦音（经过音）只用于弱拍与反拍
- 例外：挂留、倚音、蓝调音可故意落在强拍；系统提示出界时，先判断是否是有意借调/离调
- 和弦外音（经过/邻音/先现/延留/倚音）的位置与解决规则见 `melody-chord-writing.md` §3.2

### 规则 3 — 节奏呼吸
- 每 1–2 拍连续音符后必须留 0.25–0.5 拍休止
- 每 2–4 拍乐句之间必须留 0.5–1.0 拍休止
- 这是「人弹的」和「机器人弹的」的头号区别——歌手要换气
- 例外：EDM、Lo-fi、极简乐可连续律动，用音色/低音变化代替休止

### 规则 4 — 力度弧线
每个乐句必须有力度弧线，禁止一条直线：
```
流行副歌: 80 → 90 → 105 → 95 → 75    (钟形)
铺垫段:   65 → 72 → 80 → 88 → 96 → 108  (线性上升)
抒情曲:   55 → 60 → 75 → 65 → 50 → 45   (平缓弧线)
```
乐句内力度极差至少 ±15（如 70–100，而不是全 85）。

### 规则 5 — 跳进/级进平衡
- **级进占比 ≈70%**（研究实证）：约 7 成音程为大二度以内级进，跳进 ≤30%，旋律才「可唱」
- ≥4 半音的大跳之后，必须反向级进解决（约 70% 的自然旋律如此，post-skip reversal）
- 好: `E4↑G4↑C5↓B4↓G4`（跳上 C 后逐步下行）、`C5↓A4↓F4↑G4↑A4`
- 坏: `C4↑D4↑E4↑F4↑G4`（纯音阶=机器人）、`C4↑G4↑C5↑G5`（只有大跳=断裂）
- 例外：爵士、蓝调、琶音型旋律可跳进为主；大跳后不一定要立刻反向解决

### 规则 6 — 段落对比
相邻段落必须有可感知差异：
- 主歌：中音域（55–72）、中力度（65–85）、对话式节奏
- 副歌：**比主歌高 3–5 个半音**（小三度~纯四度，如中心音 67 提到 72）、力度 +20~30（85–110）、更简单更抓耳的节奏
- 桥段：与主歌不同的音域、节奏型或和声进行
- **全曲最高音刻意安排**：放在副歌内且偏后（8 小节副歌的第 5–7 小节）或副歌开头强拍，主歌绝不提前用掉

### 规则 7 — 人性化
- 相邻两个音符力度不可完全相同（CLI 不自动抖动，写的时候自觉变化）
- 偶尔用附点节奏（0.75、1.5）打破规整八分音符的可预测性；爵士/蓝调用 **0.75/0.25 硬 swing**（网格对三连音的近似）
- Ghost note：力度 25–45、时值 0.25，插在重音之间（左手「摸弦」音/军鼓 ghost）
- 每次重复至少变化 1 个元素（音高/节奏/力度），拒绝机械复制

## 4. 多轨工作流

- 默认第一轨「旋律」。低音/和弦/铺底逐轨完成后写入同一 song.json 的 tracks 数组
- 典型顺序：旋律 → 低音 → 和弦 → 对位旋律
- 音域分工：低音 36–50、和弦 48–67、旋律 60–84、铺底 55–72
- GM 音色：0 钢琴、32/33 贝斯、48/49 弦乐、88 温暖铺底

## 5. 工作流检查清单

1. 查状态：确认当前 BPM / 调式 / 已有音符
2. 定段落：3–5 段，标注各段小节数与特征（结构模板见 pattern-library.md §5：Pop ABABCB / AABA / EDM 能量曲线 / Lo-fi 循环）
3. 定和弦：**从 pattern-library.md §1 选进行配方**（按情绪查 §1.7 决策表），整曲和弦进行写入 chords.json
4. 选织体与节奏：**从 pattern-library.md §2/§3 选伴奏织体与节奏型**（按风格查 §3 决策逻辑）
5. 查现状：看已有音符，避免重复冲突
6. 定动机：为「这一段」设计动机，**用 pattern-library.md §4 的技法发展**；乐句图式从 起承转合/period 4+4/sentence 2+2+4/AABA 系 中选一个，逐句写下终止音（规则 1 补充）
7. 写音符：和弦音落强拍 + 节奏呼吸 + 力度弧线 + 级进占比 ≈70%
8. 自检：analyze 出分后按建议修正（完整流程见 SKILL.md 五步工作流）

## 6. 规则优先级与豁免

1. 先保证「结构完整、声部清晰、风格可辨」
2. 再按默认规则写一版
3. 最后刻意打破 1–2 条默认规则，制造记忆点
4. 每次打破都在摘要中说明：`打破规则：X，目的：Y`

默认规则和豁免对照见 `anti-formula.md`。
