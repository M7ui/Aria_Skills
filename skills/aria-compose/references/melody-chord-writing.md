# 旋律编写 × 和弦编写实操手册

> 用途：写 `song.json` 前，先按本手册把「旋律用什么音、和弦怎么配、强拍落在哪里」变成明确决策。
> 阅读顺序：先看 §1 选工作流 → §2 写和弦 → §3 写旋律 → §4 对照检查 → §5 写进提示词。
> 来源：哎呀音乐《如何用 1,4,5 级为旋律配上伴奏》《一首流行歌，如何用 N 种方法来编配和弦》、音频应用论坛《如何作曲、编曲》、人人文库《编曲之万能和弦和和弦走向》、Secrets of Songwriting、Soundfly、MusicRadar、Iowa State University《Comprehensive Musicianship》。

## 1. 先选工作流

### 1.1 先和弦后旋律（适合短小、Hook 明确的段落）

1. 先定调、段落、终止点
2. 选择和弦进行，写入 `chords.json`
3. 用和弦音搭旋律骨架：强拍必须是当前和弦音
4. 在弱拍加入经过音、邻音、先现音等和弦外音
5. 按乐句结构调整时值、力度和休止

真实案例参考：李圣杰《痴心绝对》副歌的旋律与和弦贴合明显，适合先定和弦再写旋律；《千千阙歌》的前奏/间奏则是在明确和声上加入经过音，让旋律更流动。

### 1.2 先旋律后配和弦（适合先有灵感/歌词）

1. 先写出完整旋律，标记每个强拍音
2. 定调，列出该调内的所有三和弦
3. 强拍音必须被当前和弦覆盖；弱拍外音不必强配
4. 优先选“旋律音作为和弦三音”的和弦，其次选根音或五音位置
5. 再用功能链、终止式、和声节奏把候选和弦串成进行

真实案例参考：邓丽君《又见炊烟》第一乐句，每个强拍旋律音都先找“能当三音的和弦”，再结合 `I–IV–V–I` 常用进行调整。

## 2. 和弦编写实操

### 2.1 先定调、乐句与终止点

- 主歌乐句通常 4 小节；副歌乐句通常 4–8 小节
- 主歌结尾常用属和弦：旋律停在 `2` 或 `5`（少见 `7`）
- 副歌/全曲结尾常用主和弦：旋律停在 `1`
- 真实案例：周杰伦《安静》主歌结束在 `2`，配属和弦；副歌结束在 `1`，回主和弦

### 2.2 定和声节奏

- 默认每小节一个和弦；抒情歌可每两小节一个；快歌可每两拍一个
- 和弦尽量在强拍切换，不要在弱拍无理由换
- 同一段落保持相对一致的和声节奏，切换频率本身也是编曲信息

### 2.3 给旋律配和弦的优先级

给强拍旋律音配和弦时，按以下顺序找候选：

1. **旋律音作为和弦三音**：色彩最明显，最容易产生“配对了”的感觉
2. **旋律音作为和弦根音**：稳定直接，适合段落起点/终止
3. **旋律音作为和弦五音**：安定支持感，适合中段填充
4. 再用终止式和声节奏筛选，避免两个候选都能用但听感断裂

C 大调音名（C4=60）对照表：

| 旋律音 | 作根音 | 作三音 | 作五音 |
|--------|--------|--------|--------|
| C (60) | C (60,64,67) | Am (57,60,64) | F (53,57,60) |
| D (62) | Dm (62,65,69) | Bdim (59,62,65) | G (55,59,62) |
| E (64) | Em (64,67,71) | C (60,64,67) | Am (57,60,64) |
| F (65) | F (65,69,72) | Dm (62,65,69) | Bdim (59,62,65) |
| G (67) | G (67,71,74) | Em (64,67,71) | C (60,64,67) |
| A (69) | Am (69,72,76) | F (65,69,72) | Dm (62,65,69) |
| B (71) | Bdim (71,74,77) | G (67,71,74) | Em (64,67,71) |

示例：旋律第 1 拍是 C4，可以配 C（C 是根音）、Am（C 是三音）、F（C 是五音）。若乐句从 C 开始且要结束在主和弦，优先 C；若想制造柔和转暗，优先 Am。

### 2.4 用真实编配流程示例

以《又见炊烟》第一乐句的公开讲解为例，简化后的流程：

1. 第一小节旋律音 `1`：段首配主和弦 C
2. 第二小节旋律音 `1`：若作三音应配 Am，但为保持 `I–IV–V–I` 常用进行，改配 F，让 `1` 成为五音
3. 第三小节旋律音 `6`：作三音应配 F；避免连续重复，保留 F 并插入过渡和弦
4. 第四小节旋律音 `3`：作三音应配 C，形成 `I–IV–F–C` 收束

结论：配和弦不是“唯一解”，而是「强拍覆盖 + 旋律音位置 + 常用进行 + 避免重复」共同筛选。

### 2.5 用真实歌曲分析做变化

Backstreet Boys《I Want It That Way》公开分析中有几个可复制的做法：

- 两个主歌结尾都用 `E–A`，但第一段之后回 `F#m`，第二段之后接 `D(add9)`；相同尾句换了目标和弦，张力平衡完全不同
- 副歌旋律沿音阶下行，挂在一个 D 三和弦上，旋律音自然变成 `9、7、13` 延伸音；不必把每个旋律音都硬塞进三和弦
- 桥段用 4-3 挂留：`sus → 平行三和弦`，第一次按五度关系解决，第二次不按预期解决
- 末段副歌整体上移全音转调，重复同一材料也能提升高潮

### 2.6 用同一条进行发展整曲

MusicRadar 公开示例把种子进行 `C–Am–F–G` 发展成完整编曲，核心操作：

| 段落 | 做法 |
|------|------|
| Verse | `C–Am–F–G`，每和弦 2 小节，旋律用 C 大调音 |
| Bridge | 同长度换两个和弦：`Em–Am–Dm–G`，旋律上行、节奏改变 |
| Chorus | 复用主歌+桥段进行，压缩为每和弦 1 小节，旋律基本重复但局部微调 |
| Middle 8 | `Am–Em–Dm–G`，从 A 小调感进入再回 C |
| Intro/Outro | 主歌前半做前奏；副歌循环做尾奏 |

可落成本包规则：**段落对比不只靠换旋律，也可以换和弦组合、压缩和声节奏、改变旋律轮廓。**

## 3. 旋律编写实操

### 3.1 先写和弦音骨架

以 C 和弦（60,64,67）为背景，先保证强拍是 C/E/G：

```text
强拍骨架:  C4(60) @0:1,  G4(67) @2:1,  E4(64) @4:1,  C4(60) @6:1
```

骨架稳定后，在弱拍补经过音和邻音：

```text
流动版本:  C4(60)@0:0.5, D4(62)@0.5:0.5, E4(64)@1:0.5, G4(67)@2:1,
           F4(65)@3:0.5, E4(64)@3.5:0.5, C4(60)@4:1
```

其中 D4、F4 是弱拍外音，全部级进连接，不会破坏和声清晰度。

### 3.2 和弦外音（NCT）分型与 MIDI 示例

默认规则：和弦音上强拍，和弦外音上弱拍；外音要短、要级进、要解决。

| 类型 | 出现位置 | 进入方式 | 离开方式 | MIDI 示例（C 大调） |
|------|----------|----------|----------|----------------------|
| 经过音 | 弱拍 | 两个不同和弦音之间 | 级进继续 | `C4@0:0.5 → D4@0.5:0.5 → E4@1:0.5` |
| 邻音/辅助音 | 弱拍 | 从同一和弦音级进离开 | 级进回到原音 | `E4@1:0.5 → F4@1.5:0.5 → E4@2:0.5` |
| 先现音 | 弱拍 | 后一和弦音提前出现 | 直接进入新和弦 | F 和弦段尾 `G4@3.5:0.5` → 下一小节 G 和弦 `G4@4:1` |
| 延留音 | 强拍 | 前一和弦音延续到新和弦 | 下行级进解决 | G7 上 `C4@0:0.75 → B3@0.75:0.5` |
| 倚音 | 强拍 | 跳进进入 | 反向级进解决 | C 和弦上 `A4@2.5:0.25 → F4@3:0.5 → E4@3.5:0.5` |

注意：

- 经过音时值一般不大于两侧和弦音
- 延留音解决音不能提前在另一声部出现，否则失去解决感
- 同一处不要叠太多外音；先保证声部进行正确，再插入外音
- 属七和弦的七音必须下行解决，不要在七音与解决音之间插装饰

### 3.3 真实歌曲观察

- **Penny Lane（Paul McCartney）**：旋律在一个 B 和弦上用了约 10 个音高，但强拍全是和弦音，非和弦音都出现在弱拍；这解释了“一个和弦也能撑起大量旋律音”
- **《痴心绝对》副歌**：旋律围绕和弦音构建，先定和声再写旋律非常合适
- **《千千阙歌》器乐段**：和声明确，旋律通过经过音流动，适合研究“和弦音 + 外音”的写法
- **《I Want It That Way》副歌**：旋律音阶下行落在 D 三和弦上，产生 9/7/13 延伸音张力；说明旋律音也可以“主动贡献和声色彩”

### 3.4 动机发展手法

以 `C4–D4–E4–G4`（60,62,64,67）为动机：

| 手法 | 做法 | 示例 |
|------|------|------|
| 原样重复 | 完全复奏 | 第一乐句 4 小节后原样再来一次 |
| 模进 | 整体上移/下移音级 | `62,64,65` 或 `60,62,64,65` 的二度模进 |
| 环绕 | 围绕一个中心音上下装饰 | 以 E 为中心：`G-E-C-E-D-E` |
| 逆行 | 从尾到头 | `67,64,62,60` |
| 倒影 | 音程方向反转 | `60,64,67` → `60,56,53` 的调内变形 |
| 碎片化 | 取动机头两音加速重复 | `60,62,60,62,60,62`，适合 Build-up |
| 拉长/缩短 | 时值 ×2 或 ÷2 | 长音收束 / 短促爬升 |

不要连续使用同一种手法；真实编曲通常是“重复建立熟悉感，换一次变奏推进，结尾回归”。

### 3.5 轮廓、乐句与终止

- 拱形轮廓：先升后降，最高点约在乐句 2/3 处，适合副歌
- 波浪轮廓：主歌叙事，音区窄、起伏多
- 下行轮廓：收尾、平静、释然
- 乐句用问答：问句停在属音/开放音，答句停在主音/稳定音
- Period：前句 4 小节半终止，后句 4 小节完全终止
- Sentence：`2 小节动机 + 2 小节重复/模进 + 4 小节碎片化与终止`
- 起承转合：起句落主音/三音 → 承句同头、落属音 → 转句对比、落不稳定音 → 合句再现、落主音
- 顶真（鱼咬尾）：后句第一音 = 前句结束音，逐句相扣（《孟姜女》《茉莉花》手法）
- 全曲最高音放副歌偏后或副歌开头强拍，主歌不要提前用完

**乐句终止点规划表（写音符前先填）**：

| 乐句 | 图式角色 | 结束音（C 大调示例） | 结束和弦 | 句尾处理 |
|------|----------|----------------------|----------|----------|
| 第 1 句 | 起 / 问 | E4(64) 三音 或 G4(67) 属音 | C 或 G | 0.5–1 拍休止 |
| 第 2 句 | 承 / 答 | G4(67) 属音（开放） | G | 0.5–1 拍休止 |
| 第 3 句 | 转 | A4(69) 或其他不稳定音 | Am/F，可离调 | 短休止，推向合句 |
| 第 4 句 | 合 / 收束 | C4(60) 主音，长音 ≥2 拍 | C | 长音 + 渐弱 |

写完用 `analyze --key-root C4` 核对：`phrase_endings_pc` 应符合上表、`final_on_tonic=true`。

## 4. 旋律与和弦配合检查

写完 song.json / chords.json 后逐项检查：

| 检查项 | 合格标准 | 不合格表现 |
|--------|----------|------------|
| 强拍覆盖 | 第 1、3 拍多数是当前和弦音 | 强拍外音密集，听起来像跑调 |
| 外音位置 | 经过/邻音/先现音在弱拍 | 外音落在强拍且无挂留/倚音意图 |
| 外音解决 | 外音级进到和弦音 | 外音跳走，悬在半空 |
| 和声节奏 | 换和弦基本在强拍 | 弱拍换和弦、段落内节奏混乱 |
| 配和弦顺序 | 优先三音/根音/五音 | 强拍音与和弦完全无关 |
| 避免重复 | 相邻小节和弦尽量有变化 | 同一和弦连续 4 小节无变化 |
| 终止式 | 主歌可停 V，副歌/结尾停 I | 段落结束没有明确功能方向 |
| 声部进行 | 保留共同音、内声部级进 | 每小节整体平移、声部大跳 |

默认阈值：`analyze` 的强拍和弦音匹配率建议 ≥ 80%；有意使用挂留、倚音、蓝调音时可降到 60–80%，但必须在摘要记录理由。

## 5. 提示词追加块

把下面两块追加到电子/流行/钢琴等风格提示词中，强制把旋律与和弦决策写出来：

```text
旋律策略：
- 调内强拍骨架：列出每小节第 1、3 拍用的和弦音
- 弱拍外音：写明经过音/邻音/先现音各出现在哪一拍，如何解决
- 动机：2–5 音，写明重复、模进、碎片化在哪段出现
- 乐句图式：起承转合 / period / sentence / AABA 系，逐句写终止音（问句开放、答句收束、末句主音长音）
- 同头与顶真：哪些乐句共享开头轮廓；是否用后句首音 = 前句尾音
- 轮廓：主歌波浪 / 副歌拱形 / 结尾下行，最高音位置

和弦策略：
- 调式与功能链：T–S–D–T 或 ii–V–I 的完整进行
- 和声节奏：每小节/两拍/两小节一个和弦，标出强拍切换点
- 配和弦依据：每个强拍旋律音作当前和弦的根音/三音/五音
- 色彩与变化：7/9/sus、转位、借调和弦放在哪段
- 真实编曲参照：参考同调同情绪的歌曲/教程案例，写清借鉴的具体手法
```
