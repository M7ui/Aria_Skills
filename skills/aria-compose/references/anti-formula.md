# 反公式化写作：默认规则的豁免清单

> 定位：现有规则是「默认值」，不是「判决」。每首歌至少要刻意打破 1–2 条默认规则，
> 让作品有记忆点。打破规则时必须能说出「为了什么」，并在交付摘要里记录。

## 1. 默认规则 → 可打破方式

| 默认规则 | 公式化表现 | 可打破方式 |
|---------|-----------|-----------|
| 0.25 拍网格 | 全是十六分音符节奏 | 用 0.125 拍、双轨错位、微偏移力度，或 `validate` 非 strict 接受非网格 |
| 强拍 100% 落在和弦音 | 旋律永远“安全” | 把强拍故意放非和弦音：挂留、倚音、蓝调音、经过音，制造张力后解决 |
| 每 1–2 拍必须休止 | 旋律永远断断续续 | EDM、Lo-fi、极简乐可以连续律动，用音色/低音变化代替呼吸 |
| 力度极差必须 ≥15 | 每一句都在做弧线 | 极简作品可以平直力度，改用音色、织体、和声做变化 |
| 级进占比 ≈70% | 旋律像标准教程 | 爵士、蓝调、琶音型旋律可以跳进为主；大跳后不一定要立刻反向解决 |
| 3–5 个标准段落 | 永远 Intro/Verse/Chorus/Outro | 用 2 段循环、奇数小节、不对称乐句、无 Intro 直接进 |
| 常用 C/G 大调 + 万能四和弦 | 听起来都像同一首歌 | 换调式、转调、借和弦、三全音替代、持续低音、半音中音 |
| 固定音域分工 | 声部永远待在舒适区 | 旋律偶尔冲高/下沉制造极端对比 |
| 每段只加/减一层 | 能量曲线太规律 | 让某段突然抽空、换织体、换拍号，制造“断点” |

## 2. 推荐的打破方式（按影响排序）

1. **和声**：把 `I–V–vi–IV` 改成 `vi–IV–I–V`、`I–vi–ii–V`、借小调和弦、挂留延迟解决
2. **节奏**：把主歌写成 3+3+2，副歌改成反拍进入；每 4 小节塞一个 0.125 拍错位
3. **结构**：循环 A 段 5 小节再进 B 段，或副歌只写 6 小节，制造不对称
4. **旋律**：在最高音前放一个半音经过音；Hook 重复时换节奏不换音高
5. **配器**：某个段落只留低音+旋律，把和弦抽掉；或突然加入对位旋律

## 3. 豁免的纪律

- 每次循环只打破 1–2 条，其余规则保持稳定，否则会变成“乱”
- 打破规则的位置要有目的：通常在段落边界、Hook 前、终止式前
- 打破后必须回到熟悉的材料，制造“意外后归家”
- 在最终摘要中写明：`打破规则：X，目的：Y`

## 3.5 六个反模式（写之前先对照，2026-09 增补）

以下都是**实测到的失败写法**，来自人写 9 首（含两首贝多芬名作）对比机写 5 首：

| 反模式 | 症状 | 怎么修 |
|--------|------|--------|
| **音阶往返 + 素材复读** | 像练习曲；每小节同形拱 → 局部起伏多、整体无起伏 | 把长音阶换成邻音摆动/回返音型；4 小节内不得原样复读音高串 |
| **琶音跳进碎片 + 整段复制** | "上的快下的快"，一串断开的尖峰 | 降大跳频次、把碎片并成 3–4 拍乐句、用级进连接 |
| **力度公式化** | 参数达标但无处安放情感 | 去掉按序号的循环项；力度 = 强度曲线 × 拍位 × 和弦音 × 乐句位置 |
| **密度与力度双恒定** | 催眠（除非是有意的持续音型） | 至少让一条曲线在动（力度或密度） |
| **每小节同形拱** | 锯齿化，抹掉大尺度形状 | 每小节的轮廓形状要有变化，不能都是同一个拱 |
| **下行大于上行** | 听感"掉下去" | 下行平均音程 ≤ 上行 |

**注意**：「有音阶跑动」本身不是原罪——致爱丽丝有 23 音的长跑动。
关键是跑完有落点、且不是全曲只靠音阶跑动。

## 4. 和 analyze 建议的关系

`analyze` 的建议是统计提示，不是音乐判决：

- “跳进过多”：若是琶音型旋律、爵士乐句、蓝调 riff，可保留
- “音符连接太紧密”：若是 EDM、Lo-fi 循环，可保留
- “强拍非和弦音”：若是挂留、倚音、蓝调音，可保留
- “超出音阶”：若是借调、半音经过音、临时离调，可保留

保留时在摘要里说明即可，不要为了消除建议而把作品改回公式。

| 被证伪的特征/规则 | 证伪者 | 说明 |
|---|---|---|
| 密度线粗糙度可判别 | 《月光》第一乐章 | 通篇持续三连音，密度恒定是**刻意的写法**；原判据 100% 分离 → 加入名作立刻失效 |
| 附点占比可判别 | 代码本身 | 机写 3–25% vs 人写 0–5%，成因是 `if i%3==2: duration-=0.25` 这条裁剪规则——**是代码指纹，不是音乐特征** |
| 相邻力度相同可判别 | 导出方式 | 7 首人写里 5 首的力度在导出时被拉平成常数，量到的是"导出方式" |
| 级进占比是核心质量指标 | 留一法 42% | **低于瞎猜基线**；且它正是"音阶练习曲"的成因。《月光》级进仅 18% 却被它判「旋律断裂、机器味明显」 |

| **和声去重 ≥8、原样循环 ≤2 次** | Wait Day | 实质和声是 G–Am 交替、F-G-Am-G 循环 **12 遍**，比任何机写都更循环，仍然好听 |
| **密度恒定是机写特征** | Wait Day | 主段每 2 小节 14/15/14/15/16/16/15/15 音，恒定——恒定在这里是刻意的底色 |
| **力度极差 ≥15 是必要条件** | Wait Day | 全曲只有 3 档力度（96/100/101），极差 5；情感完全由音高与节奏承担 |
| **音符连接太紧密是缺陷** | Wait Day | 154/165 处首尾相接（连奏率 93%），比机写还高，仍然好听 |
| 五声率可判别 | POP909 | 人写与机写都落在 0.62–0.71，无判别力 |

### 从这张表得出的两条硬规矩

1. **一个特征能不能在不理解音乐的情况下被满足？** 能 → 它不该是闸门。
   级进占比（把跳进改级进）、呼吸（删音）、相邻力度不同（抖动）、复读检查（把重复挪到第 5 小节）——
   都能在完全不理解音乐的前提下"达标"，于是必然被局部满足，叠加起来就是
   **"什么都不违反、也什么都不说"**。四拍的代码注释就是现场证据：
   > `# 主题在 idx0 与 idx4 各陈述一次：相隔 4 小节，"复读检查"只覆盖 1–3 小节间距，`
   > `# 所以不算原地踏步；同时保证 _motif_reuse 的 3 音程窗口出现重复（动机发展 > 0）。`

2. **一个特征会不会误伤已知的好作品？** 会 → 它不该是闸门。
   拿 `Wait Day`、《月光》第一乐章、《致爱丽丝》当正例回归：任何新判定必须先在这三首上不判负。
   包内的人写基线已经给每个指标标了角色（`role=style` 禁止当判定、`role=convention_dependent`
   连跨工具比较都不该做），见 `toolkits/aria-midi/reference/human-baseline.json`。

### 关于分数

`analyze` 的总分在音符层面**没有梯度**：把一个旋律音在 ±7 半音内遍历 15 个候选，
四拍恒为 8.0、余温恒为 9.0、未寄出的信恒为 10.0——**一分不动**。
零梯度 + 双值禁令 = 只能做约束满足，这是"旋律死板、找不到情绪"的直接机制。
所以：**看 `details` 与 `--baseline` 的落点，不看总分；需要方向时，方向只能由"乐句目标"给。**
