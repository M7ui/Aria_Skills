# 反公式化写作：默认规则的豁免清单

> 定位：现有规则是「默认值」，不是「判决」。每首歌至少要刻意打破 1–2 条默认规则，
> 让作品有记忆点。打破规则时必须能说出「为了什么」，并在交付摘要里记录。

## 1. 默认规则 → 可打破方式

| 默认规则 | 公式化表现 | 可打破方式 |
|---------|-----------|-----------|
| 0.25 拍网格 | 全是十六分音符节奏 | 用 0.125 拍、双轨错位、微偏移力度，或 `validate` 非 strict 接受非网格 |
| 强拍 100% 落在和弦音 | 旋律永远“安全” | 把强拍故意放非和弦音：挂留、倚音、蓝调音、经过音，制造张力后解决 |
| 每 1–2 拍必须休止 | 旋律永远断断续续 | EDM、Lo-fi、极简乐可以连续律动，用音色/低音变化代替呼吸 |
| 力度极差必须 ≥15 | 每一句都在做弧线 | 极简作品可以平直力度，改用音色、织体、和声做变化 |
| 级进占比 ≈70% | 旋律像标准教程 | 爵士、蓝调、琶音型旋律可以跳进为主；大跳后不一定要立刻反向解决 |
| 3–5 个标准段落 | 永远 Intro/Verse/Chorus/Outro | 用 2 段循环、奇数小节、不对称乐句、无 Intro 直接进 |
| 常用 C/G 大调 + 万能四和弦 | 听起来都像同一首歌 | 换调式、转调、借和弦、三全音替代、持续低音、半音中音 |
| 固定音域分工 | 声部永远待在舒适区 | 旋律偶尔冲高/下沉制造极端对比 |
| 每段只加/减一层 | 能量曲线太规律 | 让某段突然抽空、换织体、换拍号，制造“断点” |

## 2. 推荐的打破方式（按影响排序）

1. **和声**：把 `I–V–vi–IV` 改成 `vi–IV–I–V`、`I–vi–ii–V`、借小调和弦、挂留延迟解决
2. **节奏**：把主歌写成 3+3+2，副歌改成反拍进入；每 4 小节塞一个 0.125 拍错位
3. **结构**：循环 A 段 5 小节再进 B 段，或副歌只写 6 小节，制造不对称
4. **旋律**：在最高音前放一个半音经过音；Hook 重复时换节奏不换音高
5. **配器**：某个段落只留低音+旋律，把和弦抽掉；或突然加入对位旋律

## 3. 豁免的纪律

- 每次循环只打破 1–2 条，其余规则保持稳定，否则会变成“乱”
- 打破规则的位置要有目的：通常在段落边界、Hook 前、终止式前
- 打破后必须回到熟悉的材料，制造“意外后归家”
- 在最终摘要中写明：`打破规则：X，目的：Y`

## 4. 和 analyze 建议的关系

`analyze` 的建议是统计提示，不是音乐判决：

- “跳进过多”：若是琶音型旋律、爵士乐句、蓝调 riff，可保留
- “音符连接太紧密”：若是 EDM、Lo-fi 循环，可保留
- “强拍非和弦音”：若是挂留、倚音、蓝调音，可保留
- “超出音阶”：若是借调、半音经过音、临时离调，可保留

保留时在摘要里说明即可，不要为了消除建议而把作品改回公式。
