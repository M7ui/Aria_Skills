# 乐理基础 × 风格化编曲提示词

> 用途：写歌、配和弦、做编曲前，快速把「乐理依据」翻译成「编曲决定」。
> 所有音高/和弦仍用 `aria-midi scale` 验证，不要心算。
> 来源：中文检索核实——百度百科「功能和声」「编曲」、CSDN《好和弦 #7 和弦配置与和声进行》、搜狗百科「变格终止」、DTMWiki 中文编曲百科「House」、本包 `pattern-library.md`。

## 1. 功能性乐理基础（写和弦前）

### 1.1 三大和声功能

| 功能 | 自然调内代表和弦 | 听感 | 常用去向 |
|------|----------------|------|---------|
| 主功能 T | I、vi | 稳定、回家 | I、vi → IV、V |
| 下属功能 S | IV、ii | 离开、色彩 | IV、ii → V |
| 属功能 D | V、vii° | 紧张、推进 | V → I、vi |

推荐的和声语法（终止式即”结束一句、一段或一首音乐的最后几个和弦的安排方式”）：

| 终止式 | 进行（C 大调例） | 听感与用途 |
|--------|-----------------|-----------|
| 正格终止 | `V→I`（G7→C） | 最强收束，明显解决感 |
| 完全终止 | `IV→V→I`（F→G7→C） | 完整收束，古典常用 |
| 变格终止 | `IV→I`（F→C） | 温柔收束，教堂”阿门终止”感 |
| 复式变格终止 | `V→IV→I`（G→F→C） | 变格的加强版 |
| 半终止 | 停在 `V`（G7） | “还没说完”，句中短暂停顿 |
| 阻碍终止 | `V→vi`（G7→Am） | 期待落空、意外延展，之后再来真终止 |

完满终止（最强收束感）需同时满足：强拍落主和弦、旋律停在根音、V/IV 原位连接到 I。

- 经典功能链：`I → IV → V → I`、`ii → V → I`、`vi → IV → I → V`

### 1.2 增加色彩但不失控

- **副属和弦**：`V/ii`、`V/IV`、`V/V` 本质是"目标和弦的五级属七"，塞在目标和弦前制造临时倾向，**下一拍必须解决到目标和弦，不要过度使用**
- **平行调借用**：C 大调借 Fm、Ab、Bb，产生苦甜或暗色情绪，例如 `IV → iv → I`
- **挂留延留**：`Csus4 → C`、`G7sus4 → G7 → C`，挂两拍再解决，张力最明显
- **半音经过和弦**：`Am → Ab → F`，一次少量使用，不要连续堆叠
- **色彩扩展**：maj7、min9、add9、sus2/sus4 改变风格气质，不改变功能
- **Mario 终止式**：`bVI → bVII → I`（Ab → Bb → C）三个大三和弦上行，圣洁、辉煌、有游戏感
- **五度循环**：连续属和弦 `F → B → E → A → D → G → C`，音和音之间都像"要解决"，推进感强
- **持续低音**：一个声部保持长音，其他声部和声变化，营造坚定或紧张
- **非功能和声**：不按传统功能逻辑，只看每个和弦本身的色彩与氛围（氛围音乐常用）

### 1.3 经典和弦进行库（C 大调例，音名已用 CLI 验证）

| 进行 | 和弦（C 大调） | 用途 |
|------|---------------|------|
| I–V–vi–IV | C–G–Am–F | 流行万能进行，副歌首选 |
| I–vi–IV–V | C–Am–F–G | 经典 50s/循环感 |
| I–vi–ii–V | C–Am–Dm–G | 爵士味循环，可反复 |
| I–vi–IV–V 变体 | C–Am–F–G | 适合不断重复的段落 |
| ii–V–I | Dm7–G7–Cmaj7 | 爵士基本语法，收束感 |
| 卡农进行 | C–G/B–Am–G–F–C/E–Dm–G | 低音级进下行，经典煽情 |
| 半音下行低音 | 低音线 C–B–Bb–A（上方和弦随风格自配） | 伤感、电影感 |
| Mario 终止式 | Ab–Bb–C | 副歌/结尾的辉煌收束 |

**2-5-1 转调**：`Dm7 → G7 → Cmaj7` 整组下移一个全音，即 `Cm7 → F7 → Bbmaj7`，可直接转到 B♭ 大调，段落间换调最顺滑。

## 2. 声部进行（写多轨前）

1. **保留共同音**：换和弦时，能不动的声音尽量不动
2. **级进优先**：不能保留共同音时，每声部尽量走二度
3. **低音反向**：低音上行时上方声部下行，避免所有声部同向冲
4. **音区分离**：低音 36–50、和弦 48–67、旋律 60–84，防止互相打架
5. **内声部平稳**：和弦轨不要每小节大跳换 voicing，按最近路径移动

示例：`C → F` 时保留 C4，上方声部 `E4 → F4`、`G4 → A4`，比整块和弦平移更顺。

## 3. 旋律语法

- 动机 3–5 音，先能哼出来再写长
- 级进占比约 70%，大跳不超过 30%
- 大跳（≥4 半音）后反向级进解决
- 轮廓：拱形适合副歌，波浪适合主歌，下行适合收尾
- 乐句结构：前句半终止，后句完全终止；呼句结束在开放音，应句结束在主音
- Hook 极简：2–4 个音 + 固定节奏，副歌重复 2–4 次
- 最高音放在副歌偏后或副歌开头强拍，主歌不要提前用掉
- 完整旋律实操：强拍和弦音骨架、和弦外音分型、真实歌曲案例见 `../../aria-compose/references/melody-chord-writing.md` §3

### 3.1 和弦配置规则（给旋律配和弦时）

1. **先看旋律音**：给某一拍配和弦时，选含有该旋律音的和弦，倾向性进行（如 V→I）优先
2. **避免连续重复相同和弦**：除非刻意做持续感，否则同和弦不连用两小节
3. **和弦升级**：大三和弦 → add2/add9，小三和弦 → m7，属七和弦保持原样，即刻获得风格色彩
4. **副属慎用**：每 4–8 小节一处即可，用多会稀释张力
5. 完整配和弦步骤：和声节奏、三音/根音/五音优先级、真实编曲案例见 `../../aria-compose/references/melody-chord-writing.md` §2

## 4. 风格化编曲方法

### 4.1 Pop

- 焦点是旋律和 Hook，其他配器为旋律服务
- 主歌 3–4 层，副歌 5–8 层
- 副歌尽量在前 60 秒出现
- 主歌亲密、副歌宏大，副歌音域比主歌高 3–5 半音，力度 +20~30

### 4.2 EDM / House

- 编曲本身即表演：intro → build → drop → breakdown → build → drop → outro
- 8–16 小节内逐层加入元素，禁止一次性全上
- Build 越密，Breakdown 越空，Drop 才越重
- Drop 前一拍抽空底鼓，或撤掉最后一小节低频，制造”刹车”
- House 底鼓 4/4 四踩（每拍一下），配厚重低音线与灵魂/迪斯科采样；Tropical House 是其子风格，把四踩换成稀疏拍点、配木吉他/马林巴音色即是

### 4.3 Jazz / R&B

- 用 7、9、11 和弦代替三和弦
- ii–V–I 是基本语法，配合声部进行
- 律动靠 2、4 拍和反拍，节奏可以稍靠后
- 低音走 Walking Bass：第 1 拍根音，第 4 拍倾向下一和弦

### 4.4 Tropical / Lo-fi

- 2–4 层即可，密度低，情绪靠音色和氛围
- 循环结构为主，段落之间模糊过渡
- 长音 Pad + 稀疏旋律 + 稳定的低音和打击乐
- “瑕疵感”是特征：微错位、力度不均、少量噪音感

### 4.5 密度与能量曲线

| 段落 | 层数 | 密度 | 力度 | 手法 |
|------|------|------|------|------|
| Intro | 2–3 | 稀疏 | 50–70 | 动机片段、氛围 |
| Verse | 3–4 | 中 | 65–85 | 对话式、留呼吸 |
| Pre-chorus | 4–5 | 渐密 | 75→100 | 上行、渐强 |
| Chorus | 5–8 | 满 | 90–115 | Hook、最强记忆点 |
| Bridge | 3–5 | 对比 | 70–90 | 换织体或换和声 |
| Outro | 2–3 | 渐空 | 90→50 | 抽层、下行解决 |

## 5. 风格化编曲提示词模板

把下面的模板写进 composer 提示词，再进入 aria-compose 五步工作流：

```text
请按以下编曲提示词创作，并把所有决策落到 song.json / chords.json：

- 风格：流行 / EDM / 爵士 / Tropical House / Lo-fi / 钢琴独奏
- 情绪：欢快 / 悲伤 / 紧张 / 梦幻 / 力量
- BPM 与拍号：例如 120 BPM、4/4
- 调式：例如 C major，用 scale --list 验证
- 结构：例如 Intro 4 + Verse 8 + Pre-chorus 4 + Chorus 8 + Outro 4
- 和弦策略：例如 I–V–vi–IV，副歌用 V/ii 增加紧张，结尾 IV–iv–I；可选经典进行见 §1.3（卡农 / Mario 终止式 / 2-5-1 转调 / 半音下行），转调用 2-5-1
- 和弦配置：旋律音优先配含该音的和弦，避免连续重复，升级用 add2/m7
- 音轨分工：旋律 / 低音 / 和弦 / 铺底，标注音域与 GM 音色
- 织体：例如旋律 + Alberti 分解 + 八度低音
- 密度曲线：Intro 稀疏 → Verse 中 → Chorus 满 → Outro 渐空
- 力度曲线：各段落给出力度范围，乐句内做弧线
- 张力手法：sus 挂留、抽空一拍、副歌前上行
- 目标听感：例如“像电影片尾钢琴曲，温暖但有推进感”
- 反公式化：允许有意打破 1–2 条默认规则（离调、错拍、非标准结构），并说明目的

写完后必须执行 validate --strict、analyze、generate、inspect，并交付摘要；analyze 建议若是有意风格选择，可保留并记录理由。
```

## 6. 理论到文件的映射

| 乐理/编曲决定 | 落到哪里 |
|--------------|---------|
| 和弦进行、根音、类型 | `chords.json` |
| 旋律音高、时值、力度 | `song.json` 旋律轨 |
| 伴奏织体、低音 | `song.json` 低音/和弦轨 |
| 段落密度与力度 | 各段音符数量和 velocity 范围 |
| 声部进行 | 相邻小节和弦轨的 pitch 移动尽量小 |
| 张力与释放 | sus/副属/阻碍终止 + 段落间休止 |

## 7. 反公式化豁免

- 乐理规则解释“为什么好听”，不限制“只能这样写”
- 挂留、倚音、蓝调音、借调和弦、半音经过音都是合法表达
- 0.25 网格是默认；0.125 拍、双轨错位、微偏移力度可表达更细律动
- 每个循环只打破 1–2 条默认规则，并在摘要中记录：`打破规则：X，目的：Y`
- 详细对照见 aria-compose 的 `references/anti-formula.md`
