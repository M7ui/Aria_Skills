# Pop Music Composition Guide

## Common Chord Progressions

### Four-Chord Progressions (Key of C)

**I-V-vi-IV (most common):**
```
C(60,64,67) → G(67,71,74) → Am(57,60,64) → F(65,69,72)
```

**vi-IV-I-V (sensitive):**
```
Am(57,60,64) → F(65,69,72) → C(60,64,67) → G(67,71,74)
```

**I-IV-V-I (classic):**
```
C(60,64,67) → F(65,69,72) → G(67,71,74) → C(60,64,67)
```

### Chord Extensions

**Major 7th:**
```
Cmaj7: C(60) + E(64) + G(67) + B(71)
```

**Minor 7th:**
```
Am7: A(57) + C(60) + E(64) + G(67)
```

**Dominant 7th:**
```
G7: G(67) + B(71) + D(74) + F(77)
```

## Melody Writing

### Hook Creation

**Characteristics of a good hook:**
1. **Simple**: 3-5 notes, easy to sing
2. **Repetitive**: Appears 2-4 times in chorus
3. **Rhythmic**: Clear, memorable rhythm
4. **Contour**: Arch shape (rises then falls)

**Example hook (C major):**
```
C4(60, dur:0.5) → E4(64, dur:0.5) → G4(67, dur:0.5) → E4(64, dur:0.5) → C4(60, dur:1.0)
```

### Melodic Contour

**Verse melody:**
- Range: C4(60) to G4(67)
- Contour: Wave shape, conversational
- Rhythm: Syncopated, speech-like

**Chorus melody:**
- Range: E4(64) to C5(72)
- Contour: Arch shape, peaks on hook
- Rhythm: Stronger, more on-beat

### Phrasing

**4-bar phrase structure:**
```
Bar 1-2: Statement (rising contour)
Bar 3-4: Response (falling contour)
```

**8-bar verse:**
```
Phrase 1 (bars 1-4): Main idea
Phrase 2 (bars 5-8): Variation or answer
```

## Song Structure

### Standard Pop Structure
1. **Intro** (4 bars): Establish key, tempo
2. **Verse 1** (8 bars): Story setup
3. **Pre-chorus** (4 bars): Build tension
4. **Chorus** (8 bars): Hook, peak emotion
5. **Verse 2** (8 bars): Story development
6. **Pre-chorus** (4 bars): Build tension
7. **Chorus** (8 bars): Hook repetition
8. **Bridge** (8 bars): Contrast, new perspective
9. **Chorus** (8 bars): Final hook
10. **Outro** (4 bars): Resolution

### Energy Curve
```
Intro: 40% → Verse 1: 50% → Pre-chorus: 60-80% → Chorus: 90% → Verse 2: 50% → Pre-chorus: 60-80% → Chorus: 90% → Bridge: 60% → Chorus: 100% → Outro: 30%
```

## Vocal Range Guide

### Typical Pop Vocal Ranges
- **Soprano**: C4(60) to C6(84)
- **Alto**: G3(55) to G5(79)
- **Tenor**: C3(48) to C5(72)
- **Bass**: E2(40) to E4(64)

### Melody Writing for Vocals
- Keep within one octave for verses
- Expand range for choruses
- Avoid large leaps (>4 semitones) in rapid succession
- Leave space for breathing (0.5-1.0 beat rests)

## Arrangement Tips

### Layering
1. **Foundation**: Drums + Bass
2. **Harmony**: Chords (piano, guitar, synth)
3. **Melody**: Lead vocal or instrument
4. **Countermelody**: Secondary melody, fills gaps

### Dynamics by Section
- **Intro**: Sparse, filtered
- **Verse**: Medium density, conversational
- **Pre-chorus**: Building, rising energy
- **Chorus**: Full, peak energy
- **Bridge**: Contrasting, different texture
- **Outro**: Fading, resolving

## Common Pop Song Keys

### Major Keys (bright, happy)
- **C Major**: C-D-E-F-G-A-B (all white keys)
- **G Major**: G-A-B-C-D-E-F# (one sharp)
- **D Major**: D-E-F#-G-A-B-C# (two sharps)

### Minor Keys (dark, emotional)
- **A Minor**: A-B-C-D-E-F-G (relative of C)
- **E Minor**: E-F#-G-A-B-C-D (relative of G)
- **B Minor**: B-C#-D-E-F#-G-A (relative of D)

## Hook 写作原则（研究实证）

- **极简**：多数抓耳 hook 只用 2–4 个音，重复即有效
- **副歌比主歌高 3–5 半音**：主歌中心 60–67 → 副歌中心 67–72；力度 +20~30
- **全曲最高音刻意安排**：放副歌内偏后（8 小节副歌的第 5–7 小节）或副歌开头强拍，主歌绝不提前用掉
- **标题落强拍**：歌名音节落第 1、3 拍并给最长时值
- **节奏 hook**：固定节奏型跨段重复（可换音高不换节奏）
